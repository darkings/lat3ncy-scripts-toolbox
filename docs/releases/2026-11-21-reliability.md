## 安装与兼容性

- 操作步骤统一见 [安装、更新与回滚](../RELEASING.md)。已有四份本机配置改动保留在工作区，未随可靠性提交暂存；分支中既有的默认配置变更属于 PR 审阅范围。
- Windows x64、AHK v2、Python 3.11+；WinUI 源码构建使用 .NET 10 SDK，CI 固定 10.0.404。RapidOCR 已验证独立 Python 3.14，不使用全局 3.15 加载 cp314 依赖。
- TTS 使用锁定且有哈希的 `edge-tts==7.3.1` 依赖环境；旧 7.2.8 在本机真实服务测试返回 403。OCR 当前没有完整依赖锁，安装版本需另外记录。
- `auto` 的本地 WinRT/SAPI 均失败后会在线发送待朗读文本；显式 `winrt` 保持离线。未修改 ACL 或全局 Python 包。
- HUD 的产物回滚不恢复源码、TOML 或 Python 包。跨 checkout 的实例/任务必须按现有身份检查操作。

## 剩余专项验收

- 浏览器/终端的具体选区与锚点、多显示器和不同 DPI。
- 长译文复制按钮命中、真实通知横幅；新 OCR 宿主的自动剪贴板保护探针此前因访问拒绝未完成。用户基础使用成功不替代这些专项记录。
- 合盖、睡眠、供电切换、Caffeine 到期/恢复，AirPods 建链、RGB/HID 断连与重连。
- 具体下载失败/服务异常等场景，按 [设备矩阵](../../tools/startup/README.md)逐项维护。

这些限制不阻止已确认的基础使用，但本候选不宣称全设备验收完成。下一轮优先根据真实失败证据处理专项问题，再考虑配置入口和服务切换等扩展。
