# 2026-11-22 文本工作流候选

范围对应草稿 [PR #3](https://github.com/darkings/lat3ncy-scripts-toolbox/pull/3)，基于已合并的 `main`（`9d6ad01`），本批功能提交 `c72452a`。最终提交和对应 CI 以 PR 中精确 SHA 的记录为准；此文档不代表已合并、打 tag 或发布安装包。

## 变化

- Caps+I / Raycast Screenshot Translate：原生框选 → 本地锁定 RapidOCR → 共用翻译入口 → WinUI 面板。OCR 文本直接交付，不借用剪贴板传递文字。
- 面板支持朗读/停止译文、朗读原文、重试失败段、单次切换中文/英文/自动目标。请求编号和语音 generation 阻止旧操作影响新任务；关闭取消自己的后台 Job。
- 正常退出有界回收翻译父子进程和已知临时文件；交付回调失败不再逃出定时器，正文不能伪造协议头字段。
- 原生 WinUI 设置页统一翻译引擎、回退、语言、长文和朗读音色/语速/音调/音量。非敏感偏好单独保存，修订检查和 OS 锁防止同时保存互相覆盖，不复制或重写凭证 TOML。
- 腾讯可作为首选，缺密钥或显式允许的鉴权失败静默使用 Google；保留 MyMemory 末级保底。鉴权失败冷却 300 秒，过期或凭证/腾讯配置变化后重新试探。关闭鉴权回退仍按严格模式报错。
- 长文显式开启，最多 20000 字符、200 段、120 秒；按段落及引擎字节预算分段，显示完成/失败数。部分结果明确标记未完成，重试复用当前面板已完成段。
- 只读诊断识别实际设置、回退、部分失败和交付阶段；ZIP 分享包只输出白名单元数据，统计仅覆盖保留日志窗口，不输出正文、译文、密钥、原始日志、路径和命令行。

## 兼容和数据

需要 Windows、AutoHotkey v2、Python 3.11+；OCR 工作流使用独立 Python 3.14 哈希锁环境，TTS 使用既有锁定环境。WinUI 从源码构建需要现有 .NET/Windows App SDK 工具链。没有新增第三方 Python 依赖或翻译供应商。

缺省中英自动互译、2000 字符短文上限和严格鉴权保持兼容；长文和鉴权回退必须显式开启。本机用户已授权腾讯优先及 Google 静默保底，真实密钥不可用时不发回退通知。

偏好按仓库绝对路径身份存放在 LOCALAPPDATA；移动仓库会使用新身份。显式传入其他路径的 CLI 配置保持隔离，不套用本仓库偏好。长文重试临时文件包含已完成译文，归面板所有，正常关闭、替换请求和退出时清理；强杀、断电及持续外部文件锁不保证即时清理。它不属于持久历史记录，也不进入诊断包。
