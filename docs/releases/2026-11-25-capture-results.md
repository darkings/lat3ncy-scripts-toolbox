# 2026-11-25 截图与录屏结果处理

本批完成[后续计划](../ROADMAP.md)的优先项：命名模板、完成后动作、最近结果的打开/复制/定位。历史记录见[维护任务中心](2026-11-25-maintenance-center.md)。

## 使用上的变化

- 截图/录屏设置新增 `name_template` 与 `after_action`。模板只用于额外目录副本，占位符限定为 `{mode}`、`{yyyyMMdd}`、`{HHmmss}`、`{guid8}`、`{guid}`；动作可选无、打开结果、定位结果。
- 完成后动作只在文件成功交付（completed）后执行；取消、超时、失败以及仅有部分失败的会话不会触发，也不会交付旧结果。
- 结果记录新增本地文件路径字段，设置页仅在确有可用结果时显示“打开结果/复制结果/定位结果”三个按钮；列表本身不返回文件名或路径。
- Windows 原保存位置与系统原件保持不变，工具箱只做额外副本和剪贴板交付。

## 边界

命名模板不接受路径分隔符、`..`、Windows 保留字符或未登记的占位符；同名文件追加短标识，不覆盖已有副本。最近结果操作会校验结果状态、文件存在性与扩展名；非交付状态或文件缺失只返回固定错误码。真实截图/录屏、系统通知与资源管理器定位效果仍需桌面专项验收。

## 验证与证据

通过 PowerShell 夹具验证配置解析、模板命名、原文件保留与结果路径写入；Python 夹具验证快照不返回路径、非交付状态与非法动作被拒绝。WinUI 项目 `dotnet build` 通过（0 错误）。未启动真实截图/录屏，未操作设备、常驻或四份个人配置。
