# 2026-11-25 配置备份与迁移

本批完成[后续计划](../ROADMAP.md)的下一优先项：非敏感设置导出、导入预览、版本迁移与冲突检查。历史记录见 [Raycast 参数](2026-11-25-raycast-options.md)、[HUD 复合回滚](2026-11-25-hud-rollback.md)。

## 使用上的变化

- 新增 `tools/toolbox_config_transfer.py`：`--export` 输出 JSON 备份，`--preview <file>` 只读预览，`--apply <file>` 写入。
- 备份只含白名单配置字段、校验过的翻译/朗读偏好与非敏感功能开关/键位；疑似密钥字段被跳过并列入 `skipped`，凭证文件、原始 TOML 与日志不进入备份。
- 预览逐项显示当前值、拟写入值与字段路径，列出跳过项，并检查 revision 变化与键位冲突；有冲突时不写任何文件。
- 读取时迁移旧版 `version = 0` 的分段字段列表；未知更高版本或超大文件被拒绝。

## 边界

导入是按模块逐个保存，不是跨文件原子事务；中途失败会返回已完成列表。备份不恢复密钥、连接目标、模型、虚拟环境、个人令牌或 HUD 产物；这些内容仍用各自的本机备份与恢复入口。

## 验证与证据

在本机真实配置上完成导出与只读预览（无变化、无冲突），并用固定夹具验证变化预览、应用回环、revision 冲突阻止写入、旧版迁移与非法输入拒绝。夹具测试运行在本机沙箱可写目录；常规 `run-offline-tests.ps1` 的 `tools/validation` 发现入口会在标准环境执行同一套测试。未重载常驻、未操作设备、未改动四份个人配置。
