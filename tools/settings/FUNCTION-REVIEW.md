## 已修复的非设置问题

`reload-ime-hud.ps1` 原来枚举并停止所有同名 HUD，可能影响其他仓库。现调用已有的 `Stop-ToolboxOwnedHudProcess`，在停止前核对全部实例路径及创建时间，外部仓库、无法确认归属或 PID 变化时拒绝执行。现有隔离身份回归验证这些分支；新入口回归防止重新引入直接按名停止。诊断输出也不再建议全局 `Stop-Process -Name`。

RGB 启停已统一为绝对脚本路径、PID 创建 FILETIME、Hi75 父子身份及固定任务 action 校验；控制操作与硬件写入分别使用全局互斥体。退出请求按仓库隔离、限定目标身份和有效期；设置重载复用已验证的停止链路。离线验证覆盖外部/未知/PID 变化/孤立 helper/任务归属/并发与崩溃释放，不将此视作实际灯光验收。旧版常驻不识别新退出协议时可能走已验证的强制停止，推黑效果仍需设备实测。

Caffeine 图标缺失已复现为共享 AHK JSON 读取器未处理字段间 CR/LF：多行设置被拒绝，初始策略关闭所有功能。补齐 JSON 空白处理，保留重复字段、残缺文档与尾逗号拒绝；真实只读配置探针已从解析失败恢复为启用状态。任务栏视觉结果与 Shell 注册检查分别记录，不能仅凭注册成功宣称图标位于展开区域。

## 下一批优先项

1. **HUD 重建发布事务（P1）**：新停止校验收紧了目标，旧重建命令仍直接 publish 到生产目录，缺少正式部署的完整回滚/租约。后续应复用现有构建、验证、部署入口，避免 build 失败后留下停止状态。本轮受控发布不使用旧命令。
2. **Raycast 更细的脚本参数（P2）**：当前集中入口启停已落地，已有功能参数共用现页；下一批根据实际需求扩展反馈策略、诊断范围等真正属于脚本的参数。不得将维护命令执行或管理员策略修改做成自动保存开关。
3. **本机远程桌面配置（候选）**：只做本地配置与字段校验，连接目标和凭据不入库；需先明确是否纳入工具箱，再设计连接档案、分辨率和凭据引用。

真实云端鉴权、音频听感、显示器/灯具/RDP 等效果应单列验收结果，不能用离线成功替代。
