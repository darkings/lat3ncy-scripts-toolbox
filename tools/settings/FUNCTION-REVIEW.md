## 已修复的非设置问题

`reload-ime-hud.ps1` 现在调用统一 `Rebuild-ToolboxHud.ps1`：隔离构建 HUD 与 anchor、来源/产物与 self-test 验证后，用正式事务内核统一备份/部署/失败恢复。候选在停止前后重验；只发布 HUD 和 anchor，不改音频助手。普通 AHK 重启也遵守发布锁。正式停止路径持有验证创建身份的进程句柄，退出消息带接收者 PID 校验，避免旧 `--quit` 转发器误投到变化后的全局窗口。

RGB 启停已统一为绝对脚本路径、PID 创建 FILETIME、Hi75 父子身份及固定任务 action 校验；控制操作与硬件写入分别使用全局互斥体。退出请求按仓库隔离、限定目标身份和有效期；设置重载复用已验证的停止链路。离线验证覆盖外部/未知/PID 变化/孤立 helper/任务归属/并发与崩溃释放，不将此视作实际灯光验收。旧版常驻不识别新退出协议时可能走已验证的强制停止，推黑效果仍需设备实测。

Caffeine 图标缺失已复现为共享 AHK JSON 读取器未处理字段间 CR/LF：多行设置被拒绝，初始策略关闭所有功能。补齐 JSON 空白处理，保留重复字段、残缺文档与尾逗号拒绝；真实只读配置探针已从解析失败恢复为启用状态。任务栏视觉结果与 Shell 注册检查分别记录，不能仅凭注册成功宣称图标位于展开区域。
