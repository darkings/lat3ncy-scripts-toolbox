# Raycast Scripts 设置分析

范围为版本控制中的 12 个顶层 Raycast 入口及其共用 helper。Raycast 自己的快捷键属于启动器配置，AHK 设置中的快捷键仅控制 AHK，不会改写 Raycast 键位。

| 入口 | 当前行为 / 配置来源 | 设置归属 |
| --- | --- | --- |
| toolbox-settings.ps1 | 打开现有 HUD 的设置窗口 | 入口命令，无需另设常驻开关 |
| screenshot-ocr.ps1 | 从 ocr/config.toml 选择系统 OCR / RapidOCR | 共用截图识别页，避免第二套模型配置 |
| screenshot-translate.ps1 | 共用文本工作流、OCR、翻译和朗读配置 | 共用现有三页及各自功能门控 |
| next-wallpaper.ps1 | ThemeUtils 读取壁纸池并轮换桌面/锁屏 | 共用主题、壁纸与背光页 |
| toggle-rgb.ps1 | 切换灯光禁用标记，保持 Ambient 运行 | 共用氛围灯页；“暂时熄灯”与“大功能启用”语义不同 |
| screenshot.ps1 | 打开系统截图，后台监视系统截图目录，完成后复制文件 | 适合未来截图与录屏页 |
| record-screen.ps1 | 打开系统录屏，监视系统捕获目录，完成后复制视频文件 | 适合未来截图与录屏页 |
| force-dark-titlebar.ps1 | 对指定进程窗口一次性应用深/浅/重置标题栏；支持 ProcessNames 参数 | 可将目标进程列表作为可选配置，保留明确执行按钮，不伪装为持续生效开关 |
| restart-autohotkey.ps1 | 重启当前仓库 AHK 与 HUD | 维护操作按钮 |
| reload-ime-hud.ps1 | 重建并重启定位器/HUD，保持 AHK 同步 | 开发维护操作，区别于设置的模块重载 |
| diagnose-ime-hud-anchor.ps1 | 检查运行版本，Restart 参数可触发重启 | 默认只读诊断，重启动作独立按钮 |
| fix-rdp-clipboard-prompt.ps1 | 写管理员策略，调整远程桌面重定向警告/隔离 | 系统修复操作；不应做成自动保存开关或启动时自动执行 |

## 优先扩展：截图与录屏

`capture/watch-save.ps1` 已用 Known Folder 解析系统截图/视频目录，支持 OneDrive 与本地化路径；成功后静默复制文件，避免和系统原生通知重复。当前截图最多等进程结束 180 秒，录屏等新文件 1800 秒；落盘后每 500ms 检查大小，最多 40 次，连续三次稳定后复制。

适合新增的实际配置：截图/录屏功能独立开关、完成后是否复制文件、等待超时、可选额外复制目录。保留现在的行为作为默认值，并让两个入口和后台 watcher 共用一份白名单配置。系统截图工具的原保存目录由 Windows 管理；设置“额外复制目录”不能冒充修改了系统原保存位置。下一步实施应覆盖取消捕获、长录屏、文件尚未写完、多次并发捕获的归属以及 OneDrive 目录。

## 其次：维护与诊断

可在常规页增加“诊断状态”和展开的维护区，集中显示当前仓库版本、AHK/HUD/电源/灯光运行状态，并提供现有重载/诊断入口。默认诊断只读；重建、重启和系统修复保持单独操作及各自真实生效范围，不随修改字段自动执行。

## 已有配置优先共用

翻译厂商密钥归翻译设置；OCR 模型归截图识别；壁纸目录和锁屏联动归主题；设备与颜色处理归氛围灯。这样从 AHK 和 Raycast 启动同一功能会使用同一份配置，不需要复制厂商 key 或产生入口专属覆盖。
