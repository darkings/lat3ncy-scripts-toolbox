# Raycast Scripts 设置分析

范围为版本控制中的 11 个顶层 Raycast 入口及其共用 helper。Raycast 自己的快捷键属于启动器配置，AHK 设置中的快捷键仅控制 AHK，不会改写 Raycast 键位。

## 已实施：设置面板中的 Raycast 脚本页

工具箱设置面板左侧新增 **Raycast 脚本**；标题右侧总开关和十条命令独立启停自动保存至 `tools/raycast-scripts/config.toml`，下次调用读取。**Toolbox Settings** 不受这些开关影响，避免关闭后失去恢复入口。

六条日常命令与四条维护命令分别分组。脚本加载固定布尔白名单，缺失文件沿用全部启用；格式错误、重复字段、非布尔或超限时不执行正文。新总开关使用此 TOML，未向 AHK 控制文件加入字段，旧 AHK/电源进程的配置契约保持兼容。配置页支持默认恢复与搜索。重建命令还要求重启入口开启，否则在执行正文前退出；诊断的 Restart 分支同样检查重启入口并核对退出码。

**相关功能设置** 只导航至已有页面，直接配置共享的 OCR 引擎/模型、截图录屏复制/等待/额外目录、翻译和朗读、壁纸、灯光及维护选项，不另存一套参数。维护项只是“允许调用”的开关；不会因保存而重启进程、编译、提权或修改系统策略。

Raycast 支持把脚本注册为命令、为命令设置快捷键；客户端别名、快捷键和可见性继续由 Raycast 自身管理，工具箱不改其数据库。依据：[官方 Script Commands](https://manual.raycast.com/script-commands)。官方支持脚本参数并不等于仓库应复制一套参数配置，当前面板使用仓库已有配置作为唯一来源。

本机还有 Git 忽略的远程桌面入口。未读取或迁移其连接目标、凭据及 RDP 文件，也未将其加入公共配置。若后续纳入面板，连接目标、分辨率与重定向选项应进入独立的本机私有配置；凭据不进入 Raycast 参数或公共 TOML。

## 已实施：截图与录屏

`capture/watch-save.ps1` 使用 Known Folder 解析系统截图/视频目录，成功后静默处理，避免重复系统通知。默认截图等待上限 180 秒、录屏 1800 秒；落盘后每 500ms 检查大小/修改时间，连续三次稳定且写入句柄释放后复制，整个过程受本次会话总超时限制。

现已增加截图/录屏独立启用、完成后复制、等待超时、额外复制目录，保持原默认值。入口与 watcher 共用白名单配置；同模式会话替换、写入释放与文件稳定检查避免旧监视器和未完成录屏提前处理。取消、超时、并发会话、额外目录失败及 Unicode 路径均有隔离测试。系统保存位置不变，关闭工具箱复制也不更改 Windows 自身复制设置。

## 已实施：集中诊断与维护操作

常规页现有“运行状态与版本”，手动刷新显示当前仓库提交、界面构建与 AHK/HUD/光标/电源/氛围灯进程状态，未知与未运行分别标记。检查只读，不自动修复。维护区现已提供电源、主题计划、氛围灯的独立重载及完整离线环境检查；录屏未结束或状态不明时暂缓重载，不随修改字段自动执行维护动作。Raycast 重启入口独立保留，并与正式发布共享租约。HUD 重建先在隔离目录构建验证，再统一部署 HUD 与 anchor；停止前核对进程创建身份，退出消息限定接收者 PID。其他仓库或身份不明时拒绝操作。

## 已有配置优先共用

诊断结果已增加明确处理建议、模块设置跳转和主动复制脱敏摘要，不自动调用安装、重建或系统修复。手动窗口标题栏配色功能及脚本已按用户要求移除；开发用 HUD 重建和管理员系统修复继续保留为独立命令，避免保存设置触发这些操作。

翻译厂商密钥归翻译设置；OCR 模型归截图识别；壁纸目录和锁屏联动归主题；设备与颜色处理归氛围灯。这样从 AHK 和 Raycast 启动同一功能会使用同一份配置，不需要复制厂商 key 或产生入口专属覆盖。

## 已实施：提示方式与诊断范围

Raycast 脚本页新增两项共用参数，写入 `tools/raycast-scripts/config.toml` 并由 `_lib/settings.ps1` 的固定白名单读取；未设置或格式错误时按默认处理，入口门控仍先于正文执行。

- **成功提示方式**：`success` 成功与失败都提示（默认，与既有行为一致）；`failure` 只在失败时提示；`silent` 不弹系统通知。所有顶层入口的失败/成功 Toast 统一走 `_lib/notify.ps1` 的包装函数，RapidOCR 的完成通知由 `--notify-mode` 传入同一选择；诊断入口不弹 Toast。
- **诊断输出范围**：`full` 保留日志摘录与定位细节（默认）；`brief` 只保留结论标记，不改变诊断判断，也不影响 `-Restart` 的独立门控。

这些参数只控制提示与输出详略，不改写 AHK 快捷键、Raycast 客户端键位或各模块原有配置。
