# 工具箱设置中心

Raycast 运行 **Toolbox Settings**，或翻译面板“更多操作 → 工具箱设置”。同一窗口顶部切换分类；各分类的输入在当前窗口内保留，保存仅处理当前分类，重新加载放弃当前页修改，关闭放弃所有未保存输入。

| 分类 | 设置范围 | 保存与生效 |
| --- | --- | --- |
| 翻译与朗读 | 首选引擎、回退、方向、长文、音色、语速/音调/音量 | 保存本仓库非敏感偏好，下次请求生效；可预览 TOML 后保存恢复 |
| 翻译高级 | 超时、短文上限、缓存、腾讯区域/项目、服务域名 | 更新翻译 TOML 的对应字段，下次翻译生效 |
| 朗读高级 | 合成并发、正文日志开关、缓存 | 更新朗读 TOML，下次朗读生效 |
| 截图识别 | 独立 OCR 引擎、模型预设、default/mobile 模型路径 | 下次 OCR 生效；截图翻译仍固定 RapidOCR，不自动安装或下载模型 |
| 音频切换 | 耳机/扬声器匹配、连接等待/轮询、PnP/提权策略、朗读预热 | 下次切换或预热生效，不因保存而操作设备 |
| 主题、壁纸与背光 | 调度、主题、系统/应用模式、壁纸/锁屏、鼠标方案、ThinkPad 背光 | 下次相关操作读取；调度改变后需运行 `tools/theme-scheduler/Update-ThemeSchedule.ps1` 更新既有任务 |
| 电源与唤醒 | AC/DC 睡眠/休眠/关屏、巡检、任务前缀、Caffeine、唤醒豁免 | 保存不改系统；用既有 `tools/power-policy/Restart-PowerPolicy.ps1` 入口应用，显式任务参数仍优先；变更任务前缀需手动维护安装 |
| 氛围灯 | 抓屏/帧率、滤波/色彩、暗场、OpenRGB、HI75 | 重启 Ambient 后生效；保存不启动服务、连接 HID 或改变灯光 |

已有 7 份模块配置集中在这些页面，共 109 个模块字段，加上原有翻译/朗读偏好。旧音频防抖键、旧 Lenovo 参数和旧壁纸 pick 为只读兼容项，界面注明当前行为。设备关键词用多行列表，灯区大小用 JSON 对象；空音频匹配数组在旧读取器中表示内置缺省值，设置中心拒绝空列表，避免误以为已清空匹配。

密钥不出现在窗口或 JSON 响应中，仍由原 TOML / 环境变量管理。未知字段、凭证、注释与未修改内容保留；新字段只允许显式白名单，不能借桥接指定任意文件。模块页面直接编辑对应源文件，翻译与朗读基础页沿用独立偏好，不再引入额外覆盖层。代码中的快捷键路由、内部超时契约和安装动作不属于 TOML 配置表单。

每页带来源标记、类型/范围说明和生效条件。保存先校验，再在当前仓库/模块写锁下检查文件修订，保留 BOM 与换行，用同目录临时文件原子替换；检测到外部修改则拒绝覆盖并保留输入。写锁协调工具箱写入者，不能锁住任意外部编辑器；替换前会再次核对原字节，仍不宣称能阻止所有外部程序竞态。

临时文件在写入配置内容前先复制原文件 DACL，复制失败即停止；原文件若只读或使用 EFS 加密，则拒绝窗口保存，保留其原管理方式。普通失败回收自身临时文件；强杀/断电可能留下 `.toolbox-config-*.tmp`，它包含原配置内容、已在 Git 中忽略，不属于可分享附件，不做无归属批量删除。窗口不自动提权、重装计划任务或重启硬件模块。

隔离回归覆盖 7 模块、真实 CLI、并发保存、外部修改、Windows 字面路径、注释/密钥保留、保护 DACL 和失败前不写正文。原生 `ImeHudWinUi.exe --settings-lifecycle-test` 两轮打开设置并巡检所有页面，验证未编辑时提交零变更及返回基础页后预览仍保留；只读配置，不保存真实文件，也不替代物理点击验收。
