# 工具箱设置中心

通过 Raycast **Toolbox Settings**、翻译面板“更多操作 → 工具箱设置”或主托盘打开。窗口使用原生 WinUI `NavigationView` 和内置 `TitleBar`，左侧导航、右侧配置；彩色 L Logo 同时用于标题栏和任务栏。主托盘沿用任务栏主题对应的黑白图标，可在常规设置隐藏。

## 搜索设置

使用左侧 **搜索设置**，或按 **Ctrl+F** 聚焦。输入名称/关键词后，使用上下方向键选择、Enter 打开；Escape 一次清空并关闭列表。同名设置分行显示所属分类，可联合输入英文模块标识，例如 `tts 缓存`。选择结果会展开对应分组并滚动定位控件，不会切换开关、恢复默认或执行维护动作；跨页输入仍按原自动保存流程保留。

检索范围包括模块字段（含只读兼容项）、翻译/朗读基础设置、AHK 功能与快捷键、厂商密钥入口、托盘及诊断分组。目录只取固定名称和说明，不读取配置值、现有键位、密钥或日志；搜索词不保存、不联网。配置格式错误不影响检索目录，进入相应页面后仍按原流程提示读取问题。无结果时提供短词示例，Enter 不跳转。

原生搜索框挂在 `NavigationView.AutoSuggestBox`；交互遵循 [Microsoft AutoSuggestBox 指引](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/auto-suggest-box)。

## Raycast 脚本

左侧 **Raycast 脚本** 分类配置本仓库的入口。标题右侧总开关和十条命令的独立开关均自动保存，下次调用生效：日常命令包括截图、录屏、截图识别、截图翻译、下一张壁纸和切换灯光；维护命令包括重启工具箱、重建界面与定位器、光标诊断和远程桌面剪贴板修复。关闭只阻止 Raycast 入口，不更改 AHK 或底层功能总开关。**Toolbox Settings** 始终保留，便于重新开启。

配置存于 `tools/raycast-scripts/config.toml`，全部默认开启。脚本直接读取有长度上限的布尔白名单，不依赖 Python；缺少配置沿用默认，格式错误或重复键时不执行命令。维护选项只控制入口可用性，保存时不重启、不编译、不修改系统策略。

**相关功能设置** 提供现有 OCR、截图录屏、翻译、朗读、壁纸、灯光及维护页的导航，参数仍使用原配置文件。Raycast 自身的别名、快捷键和是否显示命令仍在 Raycast 客户端配置；此页不改写客户端数据库。细项与功能检查边界见 [Raycast 设置分析](RAYCAST-SETTINGS.md) 和 [功能检查记录](FUNCTION-REVIEW.md)。

## 自动保存与默认值

开关、选项和滑块修改后自动保存；文本、数值及密钥在完成输入、离开编辑框或按 Enter 后保存。切换分类保留输入，关闭窗口先提交待保存内容。写入失败保留输入并在当前窗口提示；关闭失败时可以继续编辑或明确放弃未保存内容，不发送系统通知。

普通保存期间继续编辑时，后续输入保留并继续自动保存；存在待提交内容时不会显示“已自动保存”。关闭或提交重载前，暂时停用设置编辑，等待当前写入和此前已开始的编辑回调产生的后续草稿全部保存，再执行操作；保存失败恢复编辑，保留草稿和原有失败提示。多个操作同时等待保存时，不会由先完成的操作提前恢复编辑。

大功能开关位于标题最右侧，去除 ToggleSwitch 默认状态文字和最小宽度产生的占位。标题和正文左边距均为 24 DIP。当前页偏离默认设置时，标题旁出现 **默认**；点击自动恢复当前页的功能开关和配置。翻译/朗读基础项恢复 TOML 中的基础值并清除该页偏好覆盖，其他配置恢复白名单中的内置值，快捷键恢复当前源码默认键位。其他页和厂商密钥保留。恢复默认排队期间的后续编辑按默认值计算覆盖；连续恢复默认按各自请求处理，旧回包不会清除新请求，最终恢复会清除该页基础偏好覆盖而非固定当前默认值。

保存串行执行，使用修订校验、写锁和原子替换。编辑器不会在保存过程中重建，新输入保留。外部配置冲突拒绝覆盖，错误提示标明所属分类。失败页位于其他分类时，**查看对应分类** 只跳转并保留输入；进入该页后才显示 **丢弃此页输入并重读**，明确点击后仅重新读取此页。其他页的草稿及冲突校验继续保留，多页失败逐页处理。重新读取前先校验配置能否读取，失败时保留草稿；操作错误不会提供无关的丢弃配置入口。

## 配置备份与迁移

`python tools/toolbox_config_transfer.py --export` 生成非敏感设置备份；`--preview <file>` 逐项显示当前值与拟写入值及冲突，`--apply <file>` 才写入。备份不包含凭证、密钥、原始 TOML 或日志；旧版备份在读取时迁移。详见[安装、更新与回滚](../../docs/RELEASING.md)。

## 厂商密钥

腾讯云与阿里云分别使用原生 PasswordBox。旧密钥只显示“已配置”和来源，不传回窗口、不进入命令行或日志；首次填写一整对 ID / Secret，之后可单独替换已有字段。留空保持原值，恢复默认不会清除密钥。保存到本机翻译 TOML，临时文件先继承原文件 DACL，再写入私有字节；只读/EFS 配置仍拒绝写入。

明确从窗口保存的密钥通过厂商 `prefer_config_credentials=true` 优先于旧环境变量，避免“保存了但仍使用旧 key”。未设置该标记的原配置继续采用既有环境变量优先顺序。保存不发起网络鉴权；Google GTX 和当前 MyMemory 接口不要求密钥。在线翻译、在线朗读会将请求文本发送到对应服务。

## 需要重载的设置

待重载状态保存在 `.toolbox-state/reload-pending.json`，跨窗口保留；左侧导航底部仅在有待应用配置时显示 **重载**。点击先保存草稿，再通过固定 IPC 由现有 AHK 线程启动一次性工作进程，不增加常驻线程。

工作进程只接受 power/theme/rgb 固定操作，并校验请求期限、HUD 路径/PID/创建时间、配置修订和任务所属仓库。电源调用已有的心跳验证重载流程；主题只更新当前仓库已安装的计划，不切换桌面；RGB 只重启当前仓库拥有的 RGB-Ambient 任务，不按进程名全局结束进程，不启动 OpenRGB。禁用功能或归属不明时保留待重载状态。成功结果只清除对应且未再修改的配置；失败保留重试入口。

## 维护操作

常规 → **维护操作**分别提供电源管理、主题切换计划与氛围灯的重载按钮，无须先修改配置。点击先保存草稿，再复用同一重载流程；不会重启 AHK、HUD 或正在进行的翻译/朗读。关闭的模块不可重载，同一仓库的重载工作进程串行执行；工具箱录屏会话仍在等待或处理中、或状态无法确认时暂缓重载。窗口内显示固定结果与失败原因，不发送系统通知，也不输出异常原文。

**完整离线检查**仅核对翻译、朗读和 OCR 的配置及依赖元数据，不联网、不加载模型、不读取日志或捕获内容。临时目录可写性使用临时探针检查并清理；设置进程权限受限、临时目录不可写与依赖不匹配分别提示。结果不代表云端密钥有效或实际硬件效果；检查不会修复环境或安装依赖。

每项结果附带处理建议与 **查看对应设置** 入口，检查时间明确显示。**复制检查摘要** 仅在本次检查完成后可用，用户点击才写剪贴板；摘要通过固定字段重新生成，只含时间、版本、固定状态及建议，不包含路径、正文、密钥或原始日志。重新检查时清空旧结果，失败时不可复制过时摘要。维护区从其他页面返回时重新核对功能开关，已关闭的功能不会保留可点击的旧按钮状态。

## 维护任务中心

常规 → **维护操作** 内增加维护任务中心：显示构建、验证、部署与恢复的当前阶段和结果，并在有记录时提供“查看失败记录”。取消按钮只在构建/验证这类尚未写入生产产物的阶段可用；进入部署或恢复后不再接受取消。状态来自固定字段的本地进度文件，不输出异常原文、路径或凭证。

本中心只展示进度与固定错误类别，不会自行开始构建、部署或恢复；这些操作仍由原有 Raycast/命令行入口触发。

## 存储与兼容

非敏感基础偏好和写锁位于 Git 忽略的 `.toolbox-state/`；功能开关/键位在根目录 `.toolbox-controls.json`。旧 `%LOCALAPPDATA%/lat3ncy-toolbox/preferences/<仓库身份>/preferences.json` 仅在新文件缺失时只读兼容，首次保存迁移，原文件不删改。仓库内状态目录修复 Low 完整性 apphost 无法写用户目录锁导致的开关回弹，无需提权或修改完整性标签。

九份 TOML 按固定白名单编辑，保留未知字段、注释、BOM/换行和凭证。128 项中 125 项可编辑，3 项旧兼容字段只读。原始模型、安装项和硬件操作不会由自动保存触发。

Raycast 脚本设置盘点及后续方向见 [Raycast 设置分析](RAYCAST-SETTINGS.md)。

## 验证

离线测试覆盖全部 125 个可编辑字段、12 项基础偏好、功能/快捷键往返及凭证隐私、默认恢复、延迟重载校验。`--settings-lifecycle-test` 在只读进程巡检十一页、原生编辑器、三宽度布局和窗口生命周期；`--settings-write-test` 验证实际 apphost 权限下的隔离写入；`--settings-autosave-test` 使用固定假密钥和独立仓库验证真实计时器自动保存、跨页写入、恢复默认保留密钥、开关持久化、重载提示及系统关闭前保存。额外制造两页真实修订冲突，验证跨页恢复先导航、失败重读保留草稿、单页恢复不清除另一页开关及修订、全部处理后再次保存成功；不调用硬件或真实云服务。

并发编辑回归只在隔离夹具中暂停成功写入的回包，再提交第二次修改，覆盖基础偏好、模块参数、常规开关、模块总开关和固定假密钥，并实际读回最终值。系统关闭测试同样在第一批写入后加入后续编辑，验证最后一批也已持久化；失败路径验证编辑不会一直被禁用。测试同步点不接收任何配置内容，正式运行不能启用。

## 截图与录屏

此页共用 `tools/raycast-scripts/capture/config.toml`。截图与录屏分别提供启用、完成后复制、等待上限和额外目录四项设置，顶部总开关同时控制两个 Raycast 入口，不影响 OCR。默认等待截图 180 秒、录屏 1800 秒，均完成后复制，不额外保存。关闭工具箱复制不更改 Windows 截图工具自身的自动复制行为。

捕获结果由 Windows 写入系统 Known Folder，工具箱随后处理文件；额外目录支持环境变量，相对路径基于仓库根目录。额外保存采用唯一文件名和原子发布，不覆盖同名文件，不移动/删除系统原件；目录失败不阻止独立的剪贴板处理。自动保存配置时不创建额外目录、不运行捕获或复制文件。

截图/录屏页还可为额外目录副本设置**命名模板**（`{mode}`、`{yyyyMMdd}`、`{HHmmss}`、`{guid8}`、`{guid}`）和**完成后动作**（无 / 打开结果 / 定位结果）。模板只作用于工具箱额外复制的副本，Windows 原保存位置和原件不变；动作只在文件成功交付后执行。
“最近捕获处理”现在可在确有结果时打开、复制或定位最近文件；列表本身仍不显示文件名或路径，且取消/失败时不提供这些按钮。
每次入口登记同模式新会话，旧监视器停止处理；截图和录屏的会话彼此独立。筛选排除捕获开始前的文件，取消或超时不重新复制旧文件。监视器等待文件大小/修改时间连续稳定且写入句柄释放后处理，长录屏沿用本次等待上限，不在视频首次出现 20 秒后提前退出。系统自动保存关闭或尚无新文件时，监视器到期静默结束；不增加重复系统通知。

## 集中诊断

常规 → **运行状态与版本** → **刷新状态**。按当前仓库识别快捷键、HUD、光标定位、电源与氛围灯进程，显示提交版本与部署构建标记。仅手动查询，不启动/重启后台，不读取原文、译文、密钥或原始日志。`无法确认` 不等同于 `未运行`，氛围灯 `运行中` 仅代表进程存在，不代表实际灯光通过验证。

## 最近捕获处理结果

截图与录屏页增加 **最近捕获处理**，展开时读取，支持手动刷新。截图和录屏各保留本仓库最新会话的等待、处理完成、部分失败、失败、超时或停止结果，并分别显示剪贴板和额外目录的处理情况。Windows 没有产生新文件时，只能说明可能取消、未保存或超时，不推断为成功或确定的用户取消。

记录仅含固定状态、会话标识及 UTC 更新时间，不记录图片/视频内容、文件名、路径或异常原文。设置桥只返回状态和时间，不返回会话标识。旧会话不能覆盖新会话结果；等待状态超过会话期限且没有终态时显示“未收到处理结果”，不会一直假装运行。原有目录不可写时，剪贴板成功仍会显示为部分失败。

光标助手的运行状态由现有 AHK 定时循环每五秒发布一次，仅记录拥有者与助手 PID/创建时间及仓库身份，不包含光标坐标、窗口标题或正文。诊断同时验证两个进程身份及新鲜度；PID 复用、过期、另一仓库或权限不足都不能作为正常运行证据。这项状态证明进程归属，不保证具体应用的光标定位精度。
